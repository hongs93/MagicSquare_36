## 1. `.cursorrules` vs `.cursor/rules/*.mdc`

| 기준 | `.cursorrules` | `.cursor/rules/*.mdc` (권장) |
|------|----------------|------------------------------|

**Cursor**

## 1. YAML 문법

- 치명적 오류 없음 (PyYAML 로드 가능)
- `red_phase` 3번째 항목 `다음 단계로 진행 조건: ...` → **매핑**으로 파싱되어 리스트 형식 혼재

## 2. 누락

- `tdd_rules` 외 7개 섹션 비어 있음
- Dual-Track, Wave 등 미정의

## 3. tdd_rules ↔ forbidden

- `forbidden` 비어 있어 직접 충돌 없음
- Red 금지·테스트 약화 등 **짝 미정의**

## 4. ai_behavior

- 섹션 비어 있음
- `tdd_rules`의 pytest 실행·「의도한 Red」·커버리지는 AI 단독 강제 어려움
