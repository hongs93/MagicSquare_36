| `-k empty_list` | ❌ **3 failed** — `NotImplementedError: size validation not implemented` |

### 3.2 GREEN (본 Wave 산출물)

**수정 파일:** `src/magicsquare/boundary/validator.py`

```python
if grid is None or not grid:
    return FailureResult(
        code=INVALID_SIZE_CODE,
        message=INVALID_SIZE_MESSAGE,
        is_failure=True,
    )
```

| 설계 결정 | 근거 |
|-----------|------|
| `not grid` 사용 | 행 0(`[]`)만 포착; 리터럴 `4` 미사용 (forbidden 규칙 준수) |
| C1 분기 유지 | `grid is None` 조건 병합 — C1 회귀 없음 |
| C3~C5 미구현 | `[[]]*4`, 3×4 등은 여전히 `NotImplementedError` (의도적) |

**미수정:**

- `tests/` — assert 유지
- `src/boundary/` (Dual-Track) — 별도 Wave
- `magicsquare.control.solver` — C6 대상
