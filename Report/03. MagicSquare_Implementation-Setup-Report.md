## 3. `.cursorrules` (Cursor AI 규칙)

### 3.1 작성 경과

| 단계 | 내용 |
|------|------|
| 설계 논의 | `.cursor/rules/*.mdc` vs `.cursorrules` 비교; 섹션 분할 권장안 |
| 뼈대 | 8개 최상위 키 + 80자 `#` 구분선, 값 비움 |
| 부분 작성 | `tdd_rules`만 red/green/refactor phase 세분화 |
| 검토 | YAML 파싱·누락 섹션·`forbidden` 공백·`ai_behavior` 실행 한계 지적 |
| 완성 | 8개 섹션 전부 채움 (project, code_style, architecture, tdd_rules, testing, forbidden, file_structure, ai_behavior) |

### 3.2 최상위 섹션 요약

| 섹션 | 핵심 |
|------|------|
| `project` | 1차 Must/Won't, invariant D1~P3, Report 참조 |
| `code_style` | Python 3.10+, PEP8, type hints, Google docstring, Black 88 |
| `architecture` | ECB 3레이어, boundary→control→entity 의존 |
| `tdd_rules` | red/green/refactor — description, rules, must_not |
| `testing` | pytest, AAA, coverage 80%, fixture scope, oracle IDs |
| `forbidden` | print, 하드코딩 상수, bare except, Red 생략, 테스트 약화 등 |
| `file_structure` | `src/magicsquare/{boundary,control,entity}`, `tests/` 트리 |
| `ai_behavior` | 코딩 전·중·후, TDD 위반 시 경고 |

### 3.3 검토 시 확인된 이슈 (수정 권고)

| # | 유형 | 내용 | 조치 상태 |
|---|------|------|-----------|
| 1 | YAML | `except: pass` 등 **콜론 포함 pattern**은 따옴표 필요 | 완성본에서 인용 처리 |
| 2 | 누락 | 초기에는 7개 섹션 비어 있음 | 완성본에서 해소 |
| 3 | 정합 | `forbidden`과 `tdd_rules` 중복·짝 | 완성본에서 상호 참조 |
| 4 | 실행 | pytest·커버리지·「의도한 Red」는 AI가 환경 없이 강제 불가 | `ai_behavior`에 명시; 도구 연동은 추후 |

## 5. ECB — `User` entity (샘플)

### 5.1 위치·역할

| 항목 | 내용 |
|------|------|
| 레이어 | **entity** only |
| 목적 | 학습·QA 주체 식별 (`user_id`, `display_name`); 검증기 도메인과 분리 |
| 의존 | 표준 라이브러리(`dataclasses`)만; I/O·pytest 없음 |

### 5.2 공개 API

| API | 설명 |
|-----|------|
| `User.create(user_id, display_name)` | 불변식 검증 후 생성 |
| `User.rename(display_name)` | 불변 객체; 새 인스턴스 반환 |
| `UserValidationError` | 도메인 검증 실패 |

### 5.3 불변식

| 규칙 | 내용 |
|------|------|
| `user_id` | 비공백, 최대 64자, trim |
| `display_name` | 비공백, 최대 100자, trim |
| 불변 | `frozen=True`, `slots=True` |

### 5.4 코드 스타일 준수

- 모든 public 메서드 **Google style docstring**  
- **type hints** on parameters and returns  
- 상수 `USER_ID_MAX_LENGTH`, `DISPLAY_NAME_MAX_LENGTH` (매직 넘버 회피)
